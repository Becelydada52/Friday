# Инструкции для агента

## Язык
Всегда отвечай на русском языке, включая объяснения и комментарии в чате.
Код, названия переменных и docstring — на английском (стандарт для Python-проектов).

## Правила после КАЖДОЙ задачи на рефакторинг/перенос кода
1. Если код переносится из файла А в файл Б — обязательно удали его
   из файла А. Перенос без удаления старой копии — это баг, не фича.
2. В конце ответа покажи `git diff` по всем изменённым файлам.
3. Явно перечисли: какие файлы изменены, что удалено, что добавлено.
4. Если что-то осталось задублировано (два определения одного класса/функции
   в разных файлах) — не считай задачу выполненной, исправь это сам,
   не дожидаясь отдельного запроса.

## Общий стиль
Не добавляй функциональность, которую не просили. Не переписывай код,
не относящийся к текущей задаче.
